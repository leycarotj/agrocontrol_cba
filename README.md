# AgroControl CBA

Sistema monolítico para gestión de producción, inventario y ventas en unidades productivas del Centro de Biotecnología Agropecuaria (CBA - SENA Mosquera).

## Tecnologías
- Python 3.x
- Git / GitHub

## Estructura
- `main.py`: Punto de entrada y lógica del sistema.
- `data/`: Almacenamiento local en archivos JSON.
